## Bonham Technologies

**Agent-built software for places the cloud can't go.**
Multi-agent · multi-model · offline-deployable — from Utah.

One engineer managing a fleet of coding agents, building the tools people ask for and shipping them to run on your hardware, with your models, with the network cable unplugged if that's where you live.

### What we build

- 🤖 **Agent systems & multi-model pipelines** — writer / reviewer / auditor teams with bounded loops and a human gate where it matters. Bring your own models: open weights on your own GPUs, or frontier APIs, mixed per task.
- 🔒 **Offline & airgapped deployment** — self-contained bundles, offline package management, signed single-file builds. Nothing leaves the device unless you decide it does.
- ⚡ **Custom tooling** — web apps, APIs, CLIs and internal utilities in Python, TypeScript and Rust, delivered with tests, docs, containers and CI from day one.
- 🛡️ **Security review** — of code, and of the AI-enabled tools showing up inside companies without an engineering team behind them.

### How we work

Decide first, run agent sessions in parallel, review rather than retype, and keep a durable record. Production discipline by default: typed codebases, multi-stage CI, automated dependency and secret scanning, signed releases.
